Jornada obrigatória

Para um parceiro ficar ativo no App, passa por três etapas em sequência: Plataforma (cadastro + KYB) → Conta PJ (KYC + abertura) → Plataforma (ativação do cashback). O App é a jornada do filiado que resulta dessa ativação.

Etapas mapeadas

Cadastro Envio de docs KYB Criação de perfil KYC Ativação cashback App · filiado

Para ativar o parceiro na plataforma ele precisa estar com a conta aberta.

Maiores gargalos identificados

426 empresas travadas no KYB manual há +30 dias. Conversão real: 2.600 cadastros → 1.648 contas abertas (63,4%) em 90d · E2E = 9,1 dias. Tendência positiva: conversão subiu de 55% (mar/abr) para 70% (mai/jun).

onboarding_payments quebrado desde abr/2026: 1.145 empresas bloqueadas (1 concluiu). 5.233 parceiros ativos sem App payment habilitado — maior gap de ativação identificado.

Jornada obrigatória

Para um parceiro ficar ativo no App, passa por três etapas em sequência: Plataforma (cadastro + KYB) → Conta PJ (KYC + abertura) → Plataforma (ativação do cashback). O App é a jornada do filiado que resulta dessa ativação.

Etapas mapeadas

Cadastro Envio de docs KYB Criação de perfil KYC Ativação cashback App · filiado

Etapas 1–3 sem dados em agosto — Accounts DB (DB39) sem permissão SQL. Funil completo disponível via análise pontual com acesso direto ao banco.
