Decisão de fonte: Accounts DB prevalece sobre Mixpanel para onboarding de parceiros
Por que o Mixpanel dá números errados para onboarding de parceiros: O fluxo de cadastro começa com o usuário anônimo ($device_id) e termina com usuário identificado ($user_id). Se o Mixpanel não faz o merge dos perfis, funnels e contagens únicas quebram — o mesmo usuário vira duas pessoas distintas. Resultado: o documento anterior mostrava 837 iniciaram / 272 abriram conta via Mixpanel; o Accounts DB mostra 2.600 / 1.648 para 90 dias. A fonte correta é o Accounts DB.
